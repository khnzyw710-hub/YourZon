# UI Icons Policy

Do not use emojis anywhere in the UI. Use icons from the Lucide library (`lucide-react`) instead.
- If `lucide-react` is not installed, install it: `npm install lucide-react`
- Import icons at the top of each component: `import { IconName } from "lucide-react"`
- For every emoji in the UI, replace it with the most appropriate Lucide icon
- No emojis anywhere — not in buttons, headings, feature lists, or anywhere else
- Size and color of icons should match the surrounding text or design context
- Keep layout and structure as-is, only replace emojis with icons
